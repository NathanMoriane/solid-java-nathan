# Projeto: Princípios SOLID na Prática com Java

* *Aluno:* Nathan Gramond Moriane
* *Disciplina:* Arquitetura e Projeto de Software
* *Professor:* Henrique Santiago
* *Versão do Java:* Java 17+
* *Ferramenta de Build:* Maven

## Descrição
Repositório contendo a implementação prática dos 5 princípios SOLID (Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation e Dependency Inversion) em Java, acompanhados de exemplos de violação, refatoração e testes unitários com JUnit 5.
